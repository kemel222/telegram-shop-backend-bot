# 🤝 Вклад в проект HotSpot Shop

Спасибо за интерес к проекту! Мы приветствуем вклад от сообщества.

## 🚀 Как внести вклад

### 1. Форк репозитория
Нажмите кнопку "Fork" в правом верхнем углу страницы репозитория.

### 2. Клонирование
```bash
git clone https://github.com/kemel222/telegram-shop-backend-bot.git
cd hotspot-shop
```

### 3. Создание ветки
```bash
git checkout -b feature/amazing-feature
```

### 4. Внесение изменений
- Внесите необходимые изменения
- Убедитесь, что код соответствует стандартам проекта
- Добавьте тесты, если это необходимо

### 5. Коммит
```bash
git add .
git commit -m "Add amazing feature"
```

### 6. Push
```bash
git push origin feature/amazing-feature
```

### 7. Pull Request
Создайте Pull Request с описанием изменений.

## 📋 Стандарты кода

- **Python 3.8+** - используйте современный синтаксис
- **PEP 8** - следуйте стандартам Python
- **Docstrings** - добавляйте документацию к функциям
- **Type hints** - используйте аннотации типов
- **Тесты** - покрывайте код тестами

## 🐛 Сообщение об ошибках

При сообщении об ошибке укажите:
- **ОС**: Windows/macOS/Linux
- **Python**: версия (3.8+)
- **Шаги**: для воспроизведения ошибки
- **Ожидаемое**: поведение
- **Фактическое**: поведение
- **Логи**: если есть

## 💡 Предложение новых функций

При предложении новой функции опишите:
- **Проблему**: которую она решает
- **Решение**: предлагаемое
- **Альтернативы**: которые вы рассматривали
- **Контекст**: дополнительная информация

## 🎯 Области для вклада

- **Frontend**: улучшение UI/UX
- **Backend**: оптимизация API
- **Bot**: новые команды и функции
- **Database**: миграции и схемы
- **Documentation**: улучшение документации
- **Tests**: покрытие тестами

## 📝 Процесс ревью

1. **Автоматические проверки** - CI/CD pipeline
2. **Ревью кода** - проверка коллегами
3. **Тестирование** - проверка функциональности
4. **Мерж** - после одобрения
