# 🛍️ HotSpot Shop - Telegram Bot & Web App

Полнофункциональный интернет-магазин с Telegram ботом, веб-приложением и админ-панелью для продажи электронных сигарет и аксессуаров.

## ✨ Основные возможности

### 🤖 Telegram Bot
- **Каталог товаров** с категориями и поиском
- **Корзина покупок** с управлением количеством
- **Оформление заказов** с выбором доставки/самовывоза
- **Система скидок** (автоматические + промокоды)
- **Баланс пользователя** с кэшбэком
- **Избранное** для быстрого доступа к товарам

### 🌐 Web Application
- **Адаптивный дизайн** для мобильных устройств
- **Темная/светлая тема** с автоматическим переключением
- **Умный поиск** с поддержкой транслитерации
- **Система оплаты** (карта/СБП) с копированием данных
- **Загрузка скриншотов** подтверждения оплаты

### 👨‍💼 Admin Panel
- **Управление товарами** (добавление, редактирование, удаление)
- **Управление заказами** (статусы, уведомления)
- **Система скидок** (автоматические + промокоды)
- **Клиентская база** с балансами
- **Настройки оплаты** (карта/телефон)
- **Статистика продаж**

## 🚀 Технологии

- **Backend**: Python 3.8+, FastAPI, SQLite
- **Bot Framework**: aiogram 3.x
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Database**: SQLite с миграциями
- **Deployment**: Docker, Nginx, systemd

## 📦 Установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/kemel222/telegram-shop-backend-bot.git
cd hotspot-shop
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка окружения
```bash
cp env-example .env
# Отредактируйте .env файл с вашими данными
```

### 4. Инициализация базы данных
```bash
python init_db.py
```

### 5. Запуск приложения
```bash
python run.py
```

## ⚙️ Конфигурация

### Обязательные настройки в `.env`:

```env
# Токены ботов (получить у @BotFather)
BOT_TOKEN=your_bot_token_here
ADMIN_BOT_TOKEN=your_admin_bot_token_here

# ID администраторов (ваши Telegram ID)
ADMIN_IDS=123456789,987654321

# URL веб-приложений
WEBAPP_URL=https://your-domain.com
ADMIN_WEBAPP_URL=https://admin.your-domain.com

# Контактная информация
CONTACT_TELEGRAM=@your_username
CONTACT_VK=https://vk.com/your_username

# Настройки оплаты
PAYMENT_CARD_NUMBER=1234 5678 9012 3456
PAYMENT_CARD_HOLDER=Your Name
PAYMENT_CARD_BANK=Your Bank
```

## 🎯 Основные функции

### Система заказов
- **Самовывоз** с выбором даты и времени
- **Доставка** с указанием адреса
- **Автоматические скидки** по количеству товаров
- **Промокоды** для дополнительных скидок
- **Кэшбэк** на баланс пользователя

### Система оплаты
- **Перевод на карту** с автоматическим копированием номера
- **СБП (Система быстрых платежей)** по номеру телефона
- **Загрузка скриншотов** подтверждения оплаты
- **Автоматические уведомления** менеджеру

### Админ-панель
- **Управление товарами** с изображениями и вариантами
- **Обработка заказов** с изменением статусов
- **Система скидок** с гибкими настройками
- **Управление клиентами** и их балансами
- **Настройки оплаты** (выбор метода)

## 🔧 Развертывание

### Docker (рекомендуется)
```bash
docker-compose up -d
```

### Системные сервисы
```bash
# Копирование сервисов
sudo cp *.service /etc/systemd/system/

# Запуск сервисов
sudo systemctl enable hotspot-bot
sudo systemctl enable hotspot-admin-bot
sudo systemctl enable hotspot-server
sudo systemctl start hotspot-bot
sudo systemctl start hotspot-admin-bot
sudo systemctl start hotspot-server
```
