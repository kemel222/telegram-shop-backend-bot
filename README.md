## 📝 О проекте

**HotSpot Shop** - это полнофункциональное решение для создания интернет-магазина в Telegram. Проект включает в себя три основных компонента:

- 🤖 **Telegram Bot** - интерактивный бот для клиентов с каталогом, корзиной и оформлением заказов
- 🌐 **Web Application** - современное веб-приложение с адаптивным дизайном
- 👨‍💼 **Admin Panel** - удобная панель управления для администраторов

### 💡 Почему этот проект?

- ✅ **Полностью готов к использованию** - запустите за 5 минут
- ✅ **Без кодинга** - настройка через .env файл
- ✅ **Масштабируемый** - от малого бизнеса до крупных магазинов
- ✅ **Open Source** - бесплатно и с открытым исходным кодом
- ✅ **Активная поддержка** - регулярные обновления и исправления

## 🚀 Быстрая установка

### Требования

- Python 3.8 или выше
- Git
- Telegram аккаунт для создания ботов

### Шаг 1: Клонирование

```bash
git clone https://github.com/kemel222/telegram-shop-backend-bot.git
cd telegram-shop-backend-bot
```

### Шаг 2: Установка зависимостей

```bash
# Создание виртуального окружения (рекомендуется)
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Активация (Linux/Mac)
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### Шаг 3: Настройка

```bash
# Копирование примера конфигурации
cp env-example .env

# Отредактируйте .env файл с вашими данными
# Укажите токены ботов, ID администраторов и т.д.
```

### Шаг 4: Инициализация базы данных

```bash
python init_db.py
```

### Шаг 5: Запуск

```bash
python run.py
```

🎉 **Готово!** Ваш магазин запущен и работает!

## ⚙️ Конфигурация

### Получение токенов ботов

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен
4. Повторите для админского бота

### Настройка .env файла

```env
# =============================================================================
# Токены ботов
# =============================================================================
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz           # Основной бот
ADMIN_BOT_TOKEN=987654321:ZYXwvuTSRqponMLKjiHGFedcBA     # Админский бот

# =============================================================================
# Администраторы
# =============================================================================
ADMIN_IDS=123456789,987654321                             # Ваши Telegram ID

# =============================================================================
# Веб-приложения
# =============================================================================
WEBAPP_URL=https://your-domain.com                        # URL клиентского приложения
ADMIN_WEBAPP_URL=https://admin.your-domain.com            # URL админ-панели

# =============================================================================
# Контакты
# =============================================================================
CONTACT_TELEGRAM=@your_username                           # Telegram для связи
CONTACT_VK=https://vk.com/your_username                   # VK (опционально)

# =============================================================================
# Настройки оплаты
# =============================================================================
PAYMENT_CARD_NUMBER=1234 5678 9012 3456                   # Номер карты
PAYMENT_CARD_HOLDER=Your Name                             # Держатель карты
PAYMENT_CARD_BANK=Your Bank                               # Название банка
```

### Как узнать свой Telegram ID?

1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Отправьте любое сообщение
3. Бот пришлет ваш ID

## 🎯 Функционал в деталях

### 💰 Система скидок

<details>
<summary>Автоматические скидки</summary>

- Скидка **5%** при покупке от 3 товаров
- Скидка **10%** при покупке от 5 товаров
- Скидка **15%** при покупке от 10 товаров
- Настраиваются в админ-панели

</details>

<details>
<summary>Промокоды</summary>

- **Процентные** - скидка в процентах (например, 20%)
- **Фиксированные** - скидка в рублях (например, 500₽)
- **Баланс** - пополнение баланса пользователя
- **Одноразовые** или **многоразовые**
- **С ограничением по времени**

</details>

### 💳 Система оплаты

- **Перевод на карту** - номер карты копируется автоматически
- **СБП** - оплата по номеру телефона
- **Скриншот подтверждения** - автоматическая отправка менеджеру
- **Безопасность** - данные карты не хранятся

### 📦 Обработка заказов

1. **Новый заказ** - клиент оформляет заказ
2. **Ожидание оплаты** - клиент загружает скриншот
3. **Подтверждение** - менеджер получает уведомление
4. **Обработка** - менеджер подтверждает оплату
5. **Выполнение** - заказ готов к выдаче
6. **Завершение** - клиент получил товар

### 🎁 Кэшбэк система

- **3%** возвращается на баланс после каждой покупки
- **Баланс** можно использовать для оплаты следующих заказов
- **История** всех начислений в профиле

## 🚀 Развертывание

### 🐳 Docker (Рекомендуется)

```bash
# Сборка образа
docker build -t hotspot-shop .

# Запуск контейнера
docker run -d \
  --name hotspot-shop \
  -p 8080:8080 \
  -v $(pwd)/.env:/app/.env \
  -v $(pwd)/shop.db:/app/shop.db \
  hotspot-shop
```

## 🛠️ Технологии

### Backend
- **Python 3.8+** - основной язык программирования
- **aiogram 3.x** - современный фреймворк для Telegram ботов
- **FastAPI** - быстрый веб-фреймворк для API
- **SQLite** - легковесная база данных
- **aiohttp** - асинхронные HTTP запросы

### Frontend
- **HTML5** - современная разметка
- **CSS3** - стилизация с поддержкой темной темы
- **JavaScript (ES6+)** - интерактивность
- **Phosphor Icons** - красивые иконки

### DevOps
- **Docker** - контейнеризация
- **Nginx** - веб-сервер и прокси
- **systemd** - управление сервисами
- **Let's Encrypt** - бесплатные SSL сертификаты
